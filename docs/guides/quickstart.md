# Quick Start

## Default test credentials

- **Email**: `admin@localhost`
- **Password**: `test-password`
- **Client ID**: `test-client-id` / `local-dev`
- **Client Secret**: `local-dev-secret`

These are intentional non-production placeholders. See CONTRIBUTING.md (Test credentials).

```bash
export OAUTH_CLIENT_ID=local-dev
export OAUTH_CLIENT_SECRET=local-dev-secret
export OAUTH_REDIRECT_URI=http://localhost:3000/callback
```

For full setup, see the repository README and docs/guides/.
